# ATM and UPI Transaction Simulator 

A beginner-friendly Python project that simulates basic ATM operations and UPI payments through an interactive console-based program.

## Features

- PIN-based login with limited attempts
- Check account balance
- Deposit money
- Withdraw money with insufficient-balance checks
- Simulate UPI payments
- View successful and selected failed transactions
- Input validation and exception handling

## Technologies Used

- Python
- Jupyter Notebook

## Concepts Learned

- Variables and data types
- Conditional statements
- Loops
- Lists and the `append()` method
- Exception handling using `try` and `except`
- String formatting

## How to Run

1. Download the `.ipynb` notebook from this repository.
2. Open it using Jupyter Notebook or Google Colab.
3. Run the code cells in order.
4. Follow the on-screen menu to perform transactions.

## Note

This project is an educational simulation. It does not connect to real bank accounts or process actual payments.
